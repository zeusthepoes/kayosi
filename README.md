# KAYOSI Trading CC — consolidated website package

A responsive, multi-section website based on the supplied one-page website reference and the KAYOSI Trading CC identity.

## Included
- Full KAYOSI logo supplied by the business, preserved as the original image.
- Navy, teal-blue, gold, white and grey colour system.
- Responsive desktop and mobile navigation.
- Hero, overview, capabilities, service cards, company approach and detailed road civils and logistics sections.
- PPE category catalogue, corporate branding/embroidery section, tender/general supply, cleaning/hygiene.
- Selected supplier-brand section with image marks for Amrod, Jonsson Workwear and BOVA.
- Click-to-enquire PPE tiles and a quotation form.
- Contact details and Ballito, KwaZulu-Natal location.

## Supplier mark clarification
The South African workwear brand is officially styled **Jonsson Workwear** (two s's), so its South African logo is used rather than an invented "Johnson" logo. If a different supplier named Johnson Workwear was intended, replace the Jonsson logo image and URL with that supplier's approved artwork.

Supplier logos are remotely hosted by their respective image providers / brand asset hosts. If a supplier supplies official press assets, replace the corresponding `img src` in `index.html` and keep the same image container sizing.

## Publish to the existing GitHub Pages repository
1. Download and extract this ZIP.
2. Open the extracted `kayosi-complete` folder.
3. Upload the **contents** of `kayosi-complete` (not the folder itself) into the root of the existing `kayosi` GitHub repository, replacing `index.html`, `styles.css`, `script.js`, `robots.txt` and the `assets` folder.
4. Keep GitHub Pages configured for branch `main` and folder `/ (root)`.
5. Refresh the published site after GitHub Pages completes its deployment.

## Quote form behaviour
This is a static GitHub Pages website. The quotation form validates the required fields and opens the visitor's email application with a pre-filled message addressed to kayositrading@telkomsa.net. It does not store or send form submissions on a server. A server-backed form provider is needed for submissions without an email app.

## Content accuracy notes
The reference PDF contained claims about specific registrations/certifications, project totals, contract values, years of experience, guaranteed response times, named clients and national coverage. Those items are not carried forward as facts because they have not been independently confirmed for publication. They can be added later when KAYOSI has confirmed supporting details.

Shelving and racking are excluded from the service offering. The excluded supplier names from earlier drafts are not displayed on the website.
